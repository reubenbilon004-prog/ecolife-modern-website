# Ecolife Modern Website

A minimal React + Vite redesign for Ecolife Wellness / Ecolife Yoga, Kochi.

## Stack
- React
- Vite
- Framer Motion
- Lucide React
- CSS

## Run on Windows

```powershell
npm install
npm run dev
```

Open the local URL shown by Vite.

## Add the testimonial videos

Put the two supplied versions of the same testimonial here:

```text
public/videos/testimonial-40s.mp4
public/videos/testimonial-full.mp4
```

The ~43-second version is used in the main review section. The ~4:55 version opens from the "Open testimonial" button.

## Replace the hero visual

The current hero contains a deliberately simple placeholder. Replace it with an Ecolife image from the original website files.

## Google reviews

The site links visitors to the Ecolife Wellness Google Business listing using its Place ID. Current business data surfaced by the local listing shows a 5.0 rating from 64 reviews; the site does not copy individual Google review text until each review can be verified from the public listing.
